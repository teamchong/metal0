Features

SQL Queries

Full SQL support with SELECT, WHERE, ORDER BY, LIMIT, JOINs, and aggregates. Query remote datasets without downloading.

DataFrame API

Immer-style immutable chaining: df.filter().select().limit().collect(). Works with both local and remote data.

HTTP Range Requests

Read specific columns and rows from remote files. Query 1M+ row datasets by fetching only what you need.

Vector Search

IVF-PQ index support for approximate nearest neighbor search. Find similar vectors in milliseconds.

OPFS Storage

Cache datasets locally using Origin Private File System. Works offline after first load.

Zero Dependencies

Pure Zig compiled to WASM. No npm dependencies, no build step required. Just import and use.

Quick Start

Get started in under a minute

// Import from npm or CDN import { LanceQL, DataFrame, RemoteLanceDataset } from '@metal0/lanceql'; // Load WASM and open remote dataset const lanceql = await LanceQL.load(); const dataset = await RemoteLanceDataset.open( lanceql, 'https://data.metal0.dev/laion-1m/images.lance' ); // SQL query const result = await dataset.executeSQL( 'SELECT url, width, height FROM dataset WHERE width > 1000 LIMIT 10' ); // Or use DataFrame API const df = new DataFrame(dataset) .filter(2, '>', 1000, 'int64') .select(0, 2, 3) .limit(10); const rows = await df.collect();

API Reference

LanceQL

// Load WASM module const lanceql = await LanceQL.load(wasmUrl?); // Open remote dataset const dataset = await lanceql.openDataset(url, { version? }); // Open single file const file = await lanceql.openUrl(url);

RemoteLanceDataset

// Open dataset const dataset = await RemoteLanceDataset.open(lanceql, url, { version?, skipCache? }); // Properties dataset.totalRows // number dataset.numColumns // number dataset.columnNames // string[] // Read rows const result = await dataset.readRows({ offset, limit, columns? }); // Execute SQL const result = await dataset.executeSQL(sql);

DataFrame

// Create from dataset const df = new DataFrame(dataset); // Chain operations (immutable) df.filter(colIdx, op, value, type?) // op: '=', '!=', '<', '<=', '>', '>=' df.select(...colIndices) df.limit(n) // Execute const sql = df.toSQL(); const result = await df.collect();
